# 🌟 Minimalist Glassmorphism Quote Dashboard

A beautiful, responsive web application built with Python (Backend) and HTML/CSS (Frontend) that generates inspirational quotes categorized by area of interest and maintains a dynamic, live-logged user history.

## ✨ Features
- **Atmospheric Workspace Interface:** Beautiful dark office background paired with interactive frosted glass panels.
- **Categorized Generation:** Filter quotes smoothly through distinct interest tracks.
- **Persistent Live Log Tracking:** View a running history list featuring custom capsule category tags and clear minute-by-minute timestamps.
- **Full History Actions:** Wipe recorded logs instantly using a confirmation-tracked "Clear History" switch.

## 🛠️ Technologies Used
- **Backend:** Python
- **Frontend:** HTML5, CSS3 (Vanilla Glassmorphism Layout), JavaScript (Async Fetch API)
- **Database:** SQLite (Persistent tracking log storage)
